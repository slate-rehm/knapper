# Development Rules

## Subagents

- Use sub agents aggressively to delegate tasks. Before delegating think about how the various changes could be divided up like how a team leader creates multiple stories for a feature. Delgate one story to each agent so together they complete the entire feature. Always try to delegate stories across one to six sub agents.

- Use Composer 2.5 with normal speed for exploration and implementation tasks. Always create a follow up subagent to audit of implementation.

- Use Grok 4.5 on High with normal speed for auditing implementations and for any other kinds of tasks. All audits should include running the `vp check` command and fixing any findings.

## Planning

- Use mermaid diagrams as flowcharts to explain concepts.

- Be specific and precise.

- Plans should help us build like pottery. This means building the biggest shapes first - with less definition - and then adding details in more precise shapes later.
